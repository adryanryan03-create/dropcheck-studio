Why consensus, not a scraper?

A normal scraper gives you one machine's opinion of a web page — easy to fool, easy to fake. DropCheck runs the extraction inside GenLayer consensus: the leader renders the page and extracts the terms, then every validator renders and extracts independently. The record is stored only on an exact match. Pages whose rendered text changes between fetches (heavy JavaScript, rotating content) fail consensus and are rejected instead of being guessed at — during seeding, several well-known project pages were rejected exactly this way, and none of them appear above.

Check a drop yourself

Reads on this page are permissionless. New checks go through GenLayer Studio, where the contract is deployed:

  1. Open GenLayer Studio — it creates a funded StudioNet account for you.
  2. Run check_drop on DropCheck (0x54aD…2760) with the project or airdrop page URL.
  3. Wait for consensus, then refresh this page — if validators reproduced the same terms, the verified card appears here.
